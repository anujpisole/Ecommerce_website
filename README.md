# Ecommerce_website

An end-to-end E-commerce Website built using PHP, MySQL, HTML, CSS, and JavaScript with features like product management, secure checkout, order tracking, and an admin dashboard. This project demonstrates skills in web development, databases, and scalable application design.

🚀 Features

👤 User Side
User registration & login system.
Browse products by categories and filters.
Add to Cart and Wishlist functionality.
Order checkout with multiple payment options.
Real-time order tracking system.
Product reviews & ratings.

🛠️ Admin Side

Dashboard for sales and inventory management.
Add, update, and remove products.
Manage customer orders and returns.
Apply discounts, offers, and coupon codes.
Sales analytics with charts & reports.

🔐 Security

Encrypted user authentication.
Secure payment handling.
Role-based access (Admin / Customer).

🏗️ Tech Stack

Frontend: HTML, CSS, JavaScript, Bootstrap
Backend: PHP
Database: MySQL
Deployment (Optional): Kubernetes / Docker (for scalability)
Version Control: Git & GitHub

📊 Database Design :-
By structuring the database this way, the project allows not only e-commerce transactions but also data-driven decision-making. Business owners can:
Track sales growth over time.
Identify top-performing products & categories.
Discover loyal customers and their purchasing patterns.
Optimize inventory management.
Improve customer satisfaction with review analysis.

Users Table – stores customer details
Products Table – manages product catalog
Orders Table – handles customer orders
Payments Table – stores payment details
Reviews Table – product ratings & feedback\
